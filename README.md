# PharmaDeck

AI-powered presentations & study sheets for pharmacy students.

Built with Next.js 14, Supabase, Google Gemini, and SlidesGPT.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Environment Variables

Copy `.env.local.example` to `.env.local` and fill in your credentials.
